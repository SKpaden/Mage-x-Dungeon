# Mage-x-Dungeon
My very first attempt of a simple JavaScript minigame. Nothing special, just as a tiny starter project. Fully playable in browser, no engine or extra software necessary.<br>
No persistent memory: Reload the page or close window = all progress lost. Maybe there will be some persistent state much later, but that would require a local database Docker container.<br>
This version is the simplest and easiest to try out.


# RUN LOCALLY
1. Clone repository to local machine.
2. Open with VS Code.
3. Install Live Server Extensions (published by Ritwick Dey, >73m downloads).
4. Right click index.html and select "Open with Live Server".
    - Alternative: XAMPP for Windows: clone folder into the htdocs folder in xampp folder.
5. Game opens in browser at http://127.0.0.1:5500 (auto-reloads on changes, so feel free to change stuff).


# I DON'T WANT TO RUN IT LOCALLY AND/OR NOT CLONE IT
No problem. The whole game is also available 24/7 at this address powered by Github pages: https://skpaden.github.io/Mage-x-Dungeon/ <br>
However, this version hosted by Github is slightly slower compared to running it locally, but it's still playable.
